# WaxMorph

Differentiable morphogenesis and shape-assembly on NVIDIA Warp.

WaxMorph integrates three approaches to generating biological shapes under biophysical constraints:

- **Forward simulation** — mechanochemical dynamics with cell division
- **Emulation of non-growing tissues** — learn update rules that assemble a target shape
- **Emulation of growing tissues** — learn rules that grow seed cells into a target shape
